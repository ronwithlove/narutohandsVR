# 忍术练习 VR（narutohandsVR）

在 Meta Quest 的浏览器里，用**手部追踪**结印。做出某个结印，面前会出现文字和粒子特效；按顺序做完一套结印，会释放对应的忍术。

这是 [narutohands](https://github.com/ronwithlove/narutohands)（摄像头版）的 VR 版本：页面划分（忍术练习 / 手势录制 / 忍术录入）、12 张结印参考图、中英双语、连招规则都和原来一致。识别部分重新做了，直接使用头显提供的 25 个关节的 3D 数据。

## 在 Quest 上玩

1. 在 Quest 设置里打开**手部追踪**（设置 → 动作追踪 → 手部追踪）。
2. 用 Quest 浏览器打开部署后的网址，点「进入 VR」（或「进入 AR（透视）」，能看到自己的房间）。
3. 面前会出现一块悬浮面板。**用手柄射线加扳机，或者用手指指向后捏合**来点击按钮。`⟲` 按钮可以把面板重新放到你面前。
4. **手势录制**页：选一个结印 → 开始录制 → 倒数 3 秒，把双手摆成该结印，录 5 秒（缓慢变换角度，样本会更丰富）。录好后可以「验证当前结印」。
5. **忍术录入**页：按顺序点结印，保存成连招。VR 里没法打字，所以默认自动命名为「忍术 N」；想自定义名称，进入 VR 前先在页面下方的「新忍术名称」里输入，下一次保存就会用它。
6. **忍术练习**页：开始练习，按顺序结印，完成后显示忍术名称、手速，并有特效。

结印时请把手柄放下，只用手部追踪。两只手靠近做结印时，捏合不会被当成点击。

## 识别原理

每只手的 25 个关节先变换到「手掌坐标系」（原点在手腕，朝向中指指根，按手的大小归一化），所以手放在哪里、朝向哪里、手多大都不影响。双手结印额外记录右手相对左手的位置。匹配方式沿用原项目：对已录样本做最近邻比较，并要求保持片刻才算识别成功。

**灵敏度**可在手势录制页调整。页面右下角的调试行会显示当前最接近的结印、距离和阈值，方便调参。

## 备份与分享你的录制

页面下方有「导出结印 / 导入结印」。想让所有访问者开箱即用：导出后把文件内容放到 `data/seals.json`（格式相同），提交并推送，之后没有该结印的浏览器会自动补上。本机已有的录制不会被覆盖。

## 本地开发

```bash
npm test          # 特征提取、匹配、连招、存储的单元测试（不需要头显）
npm run dev       # 静态服务器 http://localhost:8080，桌面浏览器可预览界面，用鼠标点击
```

Quest 需要 HTTPS 或 localhost 才能进入 WebXR。最省事的是推到 GitHub Pages 再用头显打开。想在本机调试，也可以 USB 连接头显后执行 `adb reverse tcp:8080 tcp:8080`，然后在头显里打开 `http://localhost:8080`。

## 部署

推到 `main` 后，GitHub Actions 会先跑测试，再发布到 GitHub Pages。首次使用需要在仓库 Settings → Pages 里把 Source 设为 **GitHub Actions**。

## 已知限制

- 目前只在桌面浏览器里用合成手验证过；**还没有在真实 Quest 上测试过**。识别阈值（`src/matcher.js` 中的 `BASE_THRESHOLD`）是按合成数据估计的，需要用真实录制来调。
- 12 个结印多数是双手交叠，遮挡时头显的追踪可能抖动或丢点，这是最大的不确定因素。
